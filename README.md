# Loadout

Open your apps, and whole setups of them, in one click. Pin the apps you use, including portable ones, and launch groups like *Discord + OBS + your game* together.

## Download

Get **`Loadout_x.y.z_x64-setup.exe`** from the [latest release](https://github.com/ItsBryFrost/loadout-releases/releases/latest) and run it. No admin rights needed; Loadout installs for your user only. Windows 10 and 11.

Windows may say **"Windows protected your PC"** because Loadout isn't code-signed yet. Click **More info → Run anyway**.

Loadout keeps itself up to date: when a new version is out you'll see **Update to …** in the sidebar.

## Uninstall

Settings → Apps → Installed apps → Loadout → Uninstall. Tick "Delete the application data" to remove your apps and setups too.
